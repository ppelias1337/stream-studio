Stream Competitions is now an app

Everything — the competitions, the keyword giveaways and Wheel Studio — lives in one program called Stream Studio. This bookmark no longer runs the show.

  1. Open Stream Studio from the desktop or the Start menu.
  2. Pick a tab at the top: Stream Competitions, Keyword, Special Giveaways or Wheel Studio.
  3. Only one screen runs the show at a time. If it says Open on another screen, press Use it here to take over.
